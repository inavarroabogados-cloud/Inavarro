# Sintonía original: ¿Esto es legal?

Composición instrumental original, 126 BPM, La menor, ocho compases (15,238 s). Gancho de cinco notas pensado para la cadencia «¿Es-to-es-le-gal?», respuesta melódica, bajo sincopado, percusión y remate agudo. Sin muestras ni melodías de terceros. No garantiza viralidad.

MP3 mono, 22.050 Hz y 64 kbps: 122.715 bytes por nivel. Tres niveles precodificados conservan el control de volumen para iOS; WAV alternativo conserva compatibilidad. La música se descarga al activar reproducción; no se añade reproducción automática. La URL del recurso musical lleva versión para evitar reutilizar audio antiguo.

Regenerar: `python scripts/build-game-audio.py`. Compilar: `node scripts/build-game-preview.mjs`. La corrección de reproducción media-files-v4 se conserva. La prueba audible en Safari/iPhone sigue siendo necesaria después del despliegue.
